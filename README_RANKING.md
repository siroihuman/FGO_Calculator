# FGO ランキング生成 for atwiki

`siroi_human` のサーヴァント一覧ページ（`pages/54.html`）から個別サーヴァントページを取得し、宝具ランキングを自動生成する JavaScript です。

## 生成するランキング

1. 宝具火力ランキング
   - 指定した宝具Lv.1～5
   - 最低／平均／最高ダメージ
   - 1体あたりの火力
2. 宝具NP獲得量ランキング
   - 1体あたりのNP
   - 攻撃Hitによる合計NP
   - 宝具効果による即時NPリチャージ
   - 合計NP
3. 宝具スター獲得量ランキング
   - 攻撃Hitによるスター期待値
   - 宝具効果による即時スター獲得
   - 合計期待値
   - 最小～最大

## 初期条件

既存ランキングを参考に、初期状態は次の条件です。

- レアリティごとの自然上限Lv
- ATK +1000
- 宝具Lv.1（画面から1～5へ変更可）
- スキルLv.10
- Skill1～3のみ使用
- 同じSkill番号に強化前／強化後がある場合は後に掲載されたものを優先
- クラス相性・属性相性は等倍
- OC1
- クリティカルなし
- オーバーキルなし
- 全体宝具は敵3体でNP・スターを集計（1～3体へ変更可）
- 条件付き特攻は原則としてランキングへ含めない

## 既存FGO計算機との関係

計算式は `FGO_DamageCalculator_atwiki.js` の `calculateDamage()` を使用します。
個別ページのATK、N/A、スター発生率、Hit数なども既存計算機の解析関数を利用します。

そのため、同じリポジトリ `siroihuman/FGO_Calculator` に次のファイルを追加してください。

- `FGO_RankingGenerator_atwiki.js`
- `atwiki_ranking_page_code.txt`（このファイルはGitHubに置かなくても構いません）

## GitHubへ追加する手順

1. `https://github.com/siroihuman/FGO_Calculator` を開く
2. `Add file` → `Upload files`
3. `FGO_RankingGenerator_atwiki.js` をアップロード
4. Commit changes で保存

## atwikiへ設置する手順

ランキングを表示したいページを管理者のみ編集可能にしたうえで、`atwiki_ranking_page_code.txt` の内容をページ本文へ貼り付けます。

`#include_js` は使用しません。既存FGO計算機と同様に `#javascript` から jsDelivr 上の外部JavaScriptを読み込みます。

## キャッシュ

100騎以上の個別ページを毎回すべて取得しないよう、解析結果をブラウザの `localStorage` に24時間保存します。

- 通常：キャッシュがあれば再利用
- 「キャッシュ削除」：次回生成時に全ページを再取得
- 宝具Lvごとに別キャッシュ

個別ページ更新直後に古い結果が残る場合は「キャッシュ削除」を押してください。

## 注意点

ページ記述が通常テンプレートから大きく外れているサーヴァント、特殊な宝具換装、段階で宝具そのものが変化するサーヴァントなどは、追加の例外処理が必要になる場合があります。

また、次の効果は初版では自動ランキング対象外または簡略化しています。

- 敵・味方の特性を条件とする特攻
- フィールド条件付きバフ
- HP残量やターン経過で倍率が変わる効果
- 確率成功のバフ／デバフ
- 攻撃後に付与されるバフを同じ宝具Hitへ遡って適用する処理
- 特殊な宝具換装

これらは通常の「攻撃力アップ」「宝具威力アップ」「カード性能アップ」「防御力ダウン」「カード耐性ダウン」「NP獲得量アップ」「スター発生率アップ」については自動取得します。
