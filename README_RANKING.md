# FGO ランキング生成 for atwiki

`siroi_human` のサーヴァント一覧ページ（`pages/54.html`）から個別サーヴァントページを取得し、宝具火力・NP獲得量・スター獲得量を自動集計する JavaScript です。

## ver 1.1.0

計算精度と表示デザインを全面的に見直しました。

- Skill1～3の効果量を「行の最後の数字」ではなく、表の `Lv.10` 列から取得
- 持続ターン・回数・説明文中の数字を効果量として誤認する問題を修正
- 「カード性能アップブースト状態」などを通常のカード性能アップとして誤加算しないよう修正
- 条件付き特性・フィールド・HP依存・確率効果を無条件で適用しないよう判定を強化
- 「通常攻撃のHit数2倍」を宝具Hit数へ誤適用しないよう修正
- 攻撃時のダメージ前に付与する防御力ダウン等へ対応
- 与ダメージプラス／被ダメージプラス／無条件の特攻威力アップを計算へ追加
- スキルによる即時NP増加、NP獲得状態、即時スター獲得、毎ターンスター獲得をランキングへ追加
- 宝具の攻撃前効果と攻撃後効果を分離して処理
- 宝具Lv指定とOC1を別々に扱うよう修正
- 火力・NP・スターすべて「スキル無／スキル有」を同じ表で比較
- 既存ツールと同じ青系UIへ変更
- キャッシュをver 1.1.0用に更新

## ランキング条件

### 宝具火力

既存の宝具ダメージランキングを基準にしています。

- レアリティごとの自然上限Lv
- ATK +1000（画面で解除可）
- 宝具Lv.1～5を選択
- OC1
- スキルLv10
- Skill1～3のみ使用
- 強化後スキル・強化後宝具を優先
- クラス相性・属性相性は等倍
- 全体宝具も1体あたりのダメージ
- 条件付き特攻は通常行へ自動適用しない

### NP獲得量

- DTDR 100%
- クリティカルなし
- オーバーキルなし
- 全体宝具は敵3体を初期値とし、1～3体へ変更可能
- Quick / Arts性能、カード耐性ダウン、NP獲得量アップを反映
- 即時NP増加、宝具リチャージ、毎ターンNP獲得状態の1回分を「追加NP」として表示
- 宝具攻撃によるNPと追加NPを分けて表示

### スター獲得量

- DSR 0%
- クリティカルなし
- オーバーキルなし
- 全体宝具は指定した敵数で集計
- カード性能、スター発生率アップを反映
- 即時スター獲得、毎ターンスター獲得の1回分を「追加」として表示

## 画面

表示デザインは、同Wikiのステータス計算機・ダメージ計算機・データオートフィルと同系統の構成です。

- 薄い青の外枠
- 白いセクションカード
- 青い左線付き見出し
- 青い操作ボタン
- Quick＝緑、Arts＝青、Buster＝赤
- 横幅が狭い画面では操作欄を自動的に折り返し
- 結果表は横スクロール可能

## atwikiへの設置

ランキングを表示したいページへ `atwiki_ranking_page_code.txt` の内容を貼り付けます。

現在の読込先は ver 1.1.0 を含む確定コミットへ固定しています。

```text
https://cdn.jsdelivr.net/gh/siroihuman/FGO_Calculator@53650ec0ad40a32c655ec3ff9bf91f4196cde4c0/FGO_RankingGenerator_atwiki.js
```

`@main` ではなく確定コミットを使うため、jsDelivrのブランチキャッシュで旧版が残る問題を避けられます。

## キャッシュ

個別ページを毎回すべて取得しないよう、解析結果をブラウザの `localStorage` に24時間保存します。

- 通常：保存済みデータを再利用
- 「データを再取得」：キャッシュを消して全ページを再解析
- 宝具Lvごとに別キャッシュ
- ver 1.0.0 のキャッシュはver 1.1.0では使用しません

## 自動適用しない効果

対象を一意に決められない効果は、誤ったランキングにしないため通常値へ自動適用しません。

- 〔悪〕など敵・味方の特性が必要な特攻／バフ／デバフ
- 特定フィールド限定
- HP残量依存
- 回数・所持数などに応じて倍率が変化
- 確率成功
- 通常攻撃時・被ダメージ時など、現在の宝具より後に発動する効果
- 特殊な宝具換装や複雑な選択式効果

## 検査

ver 1.1.0では以下を回帰テストしています。

- Lv.10列の正確な取得
- 持続ターン・回数の誤認防止
- ブースト状態の誤加算防止
- 条件付き防御力ダウンの除外

- 宝具LvとOCの分離
- スキルによるNP増加・スター獲得の加算
- 八百屋お七の旧ランキング条件における火力係数の整合性
