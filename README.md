# FGO ダメージ・NP・スター計算機 for atwiki

atwiki の各サーヴァント個別ページへ、閉じた状態の計算機を自動設置する JavaScript です。

計算機では、次の結果を同時に表示します。

- ダメージ最小値・200通り平均・基準値・最大値
- NPリチャージ量
- スター獲得期待値
- スター獲得数の最小～最大

## ver.1.1.0 の主な機能

`FGO_DamageCalculator_atwiki.js` を共通メニューから1回読み込ませると、サーヴァント個別ページを自動判定します。

- 「性能」の直前へ計算機を自動挿入
- 「性能」がないページでは「プロフィール」の直前へ挿入
- 最初は折りたたんだ状態で表示
- 関係のないページには計算機を挿入しない

ページ内の基本情報表と隠しステータス表から、次の項目を自動入力します。

| 自動入力項目 | 読み取り元 |
| --- | --- |
| サーヴァント名 | 基本情報の「真名」 |
| 攻撃側クラス | 基本情報の「Class」 |
| ATK | レアリティに対応する自然上限LvのATK |
| N/A | 隠しステータスの「N/A」 |
| SR | 隠しステータスの「スター発生率」 |
| Quick・Arts・Buster・EX・宝具のHit数 | 隠しステータスの「ヒット数」 |
| 宝具カード種類 | 宝具表の「Card」 |
| 宝具倍率 | 最後に掲載された攻撃宝具表の宝具Lv.1倍率 |

ATKなどの自動入力後も、各入力欄は自由に編集できます。概念礼装、フォウ、クラススコアなどを加えた最終ATKへ変更して使用してください。

## GitHubへの追加・更新方法

対象リポジトリは次の場所です。

```text
https://github.com/siroihuman/FGO_Calculator
```

ChatGPTから更新済みの場合は、GitHubのリポジトリを開き、`FGO_DamageCalculator_atwiki.js` の先頭付近が `const VERSION = "1.1.0";` になっていることを確認してください。

自分でブラウザから更新する場合は、次の手順です。

1. GitHubで `siroihuman/FGO_Calculator` を開きます。
2. `FGO_DamageCalculator_atwiki.js` を開きます。
3. 右上の鉛筆アイコン「Edit this file」を押します。
4. 新しいJavaScriptの内容へ置き換えます。
5. ページ下部の「Commit changes...」を押します。
6. 説明欄へ、たとえば `サーヴァントページへの自動設置に対応` と入力します。
7. もう一度「Commit changes」を押して確定します。

ファイルを新規アップロードする場合は、リポジトリ上部の「Add file」から「Upload files」を選びます。

## atwikiへの設置方法

### 重要：`include_js` は使用しません

この計算機は大きなJavaScriptであるため、`#include_js` では次のエラーになることがあります。

```text
include_js plugin Error : このプラグインで利用できない命令または文字列が入っています。
```

`#include_js(...)` は削除し、管理者用の `#javascript` プラグインで外部ファイルを読み込んでください。

### おすすめ：共通メニューページへ1回だけ貼る

1. atwikiへ管理者としてログインします。
2. サイトの「メニュー」ページを編集します。
3. 編集モードが「PukiWikiライクモード」であることを確認します。
4. ページの閲覧・編集権限を確認し、JavaScriptを置ける管理者用ページにします。
5. 次の4行をメニュー本文の末尾へ貼り付けます。
6. 保存し、サーヴァント個別ページを開き直します。

```text
#javascript(){{
<script type="text/javascript" src="https://cdn.jsdelivr.net/gh/siroihuman/FGO_Calculator@main/FGO_DamageCalculator_atwiki.js?v=1.1.0"></script>
}}
```

メニューは各ページで読み込まれるため、全サーヴァントページを1ページずつ編集する必要はありません。JavaScriptは基本情報表と隠しステータス表がそろったページだけを判定し、「性能」または「プロフィール」の直前へ計算機を追加します。

### 個別ページだけで使用する場合

共通メニューへ置かず、特定のサーヴァントページの末尾へ同じ4行を貼っても動作します。自動挿入される場所は、コードを貼った場所ではなく「性能」または「プロフィール」の直前です。

### 表示確認

サーヴァント個別ページを開くと、次のような閉じた見出しが表示されます。

```text
エインガナ：ダメージ・NP・スター計算機（ページ情報を自動入力）
```

見出しを押すと計算機が開きます。上部の「ページ情報」に、サーヴァント名、自然上限LvのATK、N/A、SRが表示されていれば自動取得成功です。

カード種類を変更すると、そのカードのHit数へ自動的に切り替わります。「攻撃種別」を「宝具」にすると、宝具のカード種類、Hit数、宝具Lv.1倍率へ切り替わります。

入力を変更した後、ページ情報へ戻したい場合は「ページ情報を再入力」を押してください。「入力を初期化」を押した場合も、そのサーヴァントの基本情報へ戻ります。

## 更新が見えない場合

GitHubの更新直後は、jsDelivrやブラウザのキャッシュにより古いJavaScriptが表示される場合があります。

1. ブラウザで強制再読み込みします。
2. まだ変わらない場合は、URL末尾のバージョン番号を変更します。

```text
変更前：?v=1.1.0
変更後：?v=1.1.1
```

番号はキャッシュを区別する目印です。JavaScript本体のバージョンと完全一致していなくても読み込みには影響しません。

## 表示されない場合の確認項目

1. GitHubリポジトリがPublicになっているか確認します。
2. リポジトリ名が `FGO_Calculator` になっているか確認します。
3. ファイル名の大文字・小文字が `FGO_DamageCalculator_atwiki.js` と一致しているか確認します。
4. `#include_js` が残っていないか確認します。
5. `#javascript(){{` と最後の `}}` が別々の行にあるか確認します。
6. JavaScriptを置いたatwikiページが、プラグインを使用できる管理者用ページか確認します。
7. 対象ページに「Class」「Rare」「ATK」「N/A」「スター発生率」「ヒット数」が載った表があるか確認します。

## パソコン上での表示確認

`FGO_DamageCalculator_standalone.html` と `FGO_DamageCalculator_atwiki.js` を同じフォルダーに置き、HTMLファイルをダブルクリックします。

単体確認ページにはサーヴァント表がないため、ページ情報の自動取得は行われず、初期値を手動入力する通常の計算機として表示されます。

## 計算時の注意

- ダメージは「1対象に対する全Hit合計」です。Hit数を掛ける必要はありません。
- NPとスターはHitごとに計算します。
- 攻撃対象数を2以上にすると、NPとスターだけが対象数分加算されます。
- オーバーキルHit数には、撃破判定が出たHit以降の数を入力します。
- 宝具表が強化前・強化後の順で複数ある場合は、最後の攻撃宝具表を現在値として読み取ります。
- 補助宝具など、攻撃倍率が掲載されていない宝具では宝具倍率を自動取得できません。
- ページの表記や構造がテンプレートと大きく異なる場合は、該当項目を手動入力してください。

## 入力内容の保存

入力内容はブラウザ内へ自動保存されます。保存単位は「同じ端末・同じブラウザ・同じatwikiページ」です。他の端末やブラウザとは共有されません。
