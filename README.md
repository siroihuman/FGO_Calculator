# FGO ダメージ・NP・スター計算機 for atwiki

atwikiのPukiWikiライクモードで使用できる、Fate/Grand Order向け計算機です。

1回の攻撃について、以下を同時に表示します。

- ダメージ最小値・200通り平均・基準値・最大値
- NPリチャージ量
- スター獲得期待値
- スター獲得数の最小～最大

## 収録ファイル

| ファイル | 用途 |
| --- | --- |
| `FGO_DamageCalculator_atwiki.js` | 計算機本体。GitHubへ置くファイルです |
| `atwiki_page_code.txt` | atwikiのページへ貼り付けるコードです |
| `FGO_DamageCalculator_standalone.html` | パソコン上で表示確認するためのページです |
| `tests/test.js` | 計算式の確認用テストです |

## atwikiへの設置方法

### 1. JavaScriptファイルをGitHubへ置く

`FGO_DamageCalculator_atwiki.js`を、次のリポジトリの一番上の階層へアップロードします。

```text
siroihuman/FGO_Battle_Simulator
```

配置後は、次のような構成になります。

```text
FGO_Battle_Simulator/
└─ FGO_DamageCalculator_atwiki.js
```

### 2. atwikiに計算機ページを作る

1. atwikiで新しいページを作成します。
2. 編集モードを「PukiWikiライクモード」にします。
3. ページの編集権限を「管理者のみ」にします。
4. `atwiki_page_code.txt`の内容をすべて貼り付けて保存します。

貼り付ける内容は次の3行です。

```text
*FGO ダメージ・NP・スター計算機

&html(<div id="fgo-damage-calculator"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_Battle_Simulator@main/FGO_DamageCalculator_atwiki.js?v=1.0.0)
```

### 3. 更新が反映されない場合

GitHub上のJavaScriptを更新した直後は、配信側のキャッシュにより古い内容が表示されることがあります。

その場合は、atwiki側の末尾にあるバージョン番号を変更してください。

```text
変更前：?v=1.0.0
変更後：?v=1.0.1
```

## パソコン上での表示確認

`FGO_DamageCalculator_standalone.html`と`FGO_DamageCalculator_atwiki.js`を同じフォルダーに置き、HTMLファイルをダブルクリックします。

atwikiへ設置する前に、入力・計算・画面表示を確認できます。

- カード順
- 宝具倍率
- 攻撃側・防御側クラス
- クラス補正・クラス相性
- 天地人・星獣相性
- カード性能・カード耐性
- 攻撃力・防御力
- クリティカル・Extra・Busterチェイン
- 特攻威力・被ダメージ・宝具威力
- 特殊耐性・宝具特攻
- 固定ダメージ・ダメージカット

### NPリチャージ

- N/A
- 攻撃Hit数
- 攻撃対象数
- オーバーキルHit数
- DTDR
- NP獲得量アップ／ダウン
- 1st Artsボーナス

### スター

- SR

- 攻撃対象数

## 1stボーナスの扱い

通常攻撃の1stカードを計算する場合は、カード種類から対応する1stボーナスが自動選択されます。

2nd・3rd・Extra Attackでは、実際に最初に選んだカードに合わせて、次の項目を選択します。

- 1st Buster：ダメージ計算のカード項へ0.5を加算
- 1st Arts：NP獲得計算のカード項へ1.0を加算
- 1st Quick：スター発生率へ20％を加算

宝具カードは1stボーナスを後続カードへ与えますが、宝具自身は1stボーナスを受けません。そのため、宝具計算中は3項目とも無効になります。

## Hit数と攻撃対象数

- ダメージは「1対象に対する全Hit合計」です。
- ダメージへHit数を掛ける必要はありません。
- NPとスターはHitごとに計算します。
- 攻撃対象数を2以上にすると、NPとスターだけが対象数分加算されます。
- 現在の版では、すべての対象が同じDTDR・DSR・オーバーキルHit数であるものとして計算します。

例えば全体宝具で敵3体のうちオーバーキル状況が異なる場合は、対象ごとに1体ずつ計算してNP量を合計すると正確です。

## オーバーキルHit数

撃破判定が発生したHit以降の数を入力します。

6Hit攻撃の2Hit目で撃破判定が発生した場合は、2～6Hit目がオーバーキルとなるため「5」を入力します。

- NP獲得量：対象Hitのみ1.5倍
- スター発生率：対象Hitのみ30％加算

## 自動設定

攻撃側クラスからクラス補正を、防御側クラスからDTDR・DSRを自動設定します。

一般的なクラス相性も攻撃側・防御側から自動設定します。ビーストや独自クラスなど、個体固有の相性は自動判定できないため、手動指定を使用してください。

## 計算上の端数処理

- ダメージ乱数は0.900～1.099の0.001刻み、全200通りです。
- ダメージは最終段階で小数点以下を切り捨てます。
- NPは1Hit分を小数第2位まで切り捨てた後、Hit数とオーバーキル補正を適用します。
- スターは1Hitごとに最大3個です。
- スター期待値は、各Hitの確定個数と残りの抽選確率を合算した値です。

## 入力内容の保存

入力内容はブラウザ内へ自動保存されます。

保存単位は「同じ端末・同じブラウザ・同じatwikiページ」です。他の端末やブラウザとは共有されません。
